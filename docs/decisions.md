# Архитектурные решения

Короткий журнал решений: что выбрали, из чего выбирали и почему. Новое решение — новая строка, старые не удаляются, а помечаются как заменённые.

| № | Дата | Решение | Альтернативы | Почему |
|---|------|---------|--------------|--------|
| 1 | 2026-11-02 | Корпус: законы РК с adilet.zan.kz (Трудовой, Налоговый кодексы, ГК) | Документация open-source продукта, своя wiki | Реальная польза, русский и казахский языки, сложная структура (статьи, пункты) проверяет чанкинг |
| 2 | 2026-11-02 | Очередь индексации: RabbitMQ | Kafka | Нужна очередь задач, а не лог событий: ручной ack, ретраи и dead-letter есть из коробки |
| 3 | 2026-11-02 | LLM: Claude Sonnet основная, Claude Haiku резервная | OpenAI, локальная Ollama | Хорошо следует инструкциям про цитаты; резервная модель дешевле и с другими лимитами |
| 4 | 2026-11-02 | Эмбеддинги локально: multilingual-e5-large (1024 измерения) | bge-m3, API эмбеддингов | Бесплатно, поддерживает русский и казахский; bge-m3 сравним на evals (этап 7) |
| 5 | 2026-11-02 | Хранилище: PostgreSQL + pgvector + full-text | Qdrant + отдельный BM25 | Одна база для векторов, BM25, метаданных и статусов; транзакционная переиндексация |
| 6 | 2026-11-02 | Свой код на FastAPI, без LangChain | LangChain, LlamaIndex | Прозрачная отладка, каждый шаг пайплайна виден и измерим |
| 7 | 2026-11-02 | Reranker: bge-reranker-v2-m3 | Cohere Rerank API | Мультиязычный, работает на CPU |
| 8 | 2026-11-02 | HTML качаем с `old.adilet.zan.kz`, канонический URL в БД — `adilet.zan.kz` | Новый портал через его API; headless-браузер | Новый adilet.zan.kz (сборка от 2026-10-30) — SPA: в HTML нет текста, он приходит из `/api/documents`, который требует API-ключ. Старый портал отдаёт готовый HTML с текстом в `<article>`. Адрес сервера — настройка `FETCH_BASE_URL`; если старый портал отключат, придётся перейти на API нового |
| 9 | 2026-11-02 | Хеш версии — от нормализованного текста `<article>`, а не от HTML | Хеш сырого HTML | На странице есть баннер, меню и вкладки, которые меняются независимо от закона. Нормализация: единые переводы строк, `strip` строк, без пустых строк |
| 10 | 2026-11-02 | Утратившие силу документы (метка `status_yts`) загрузчик не сохраняет | Хранить со статусом | Ассистент отвечает по действующему праву; устаревшая норма в выдаче хуже, чем отсутствие ответа |
| 11 | 2026-11-02 | Первая миграция написана вручную, без `--autogenerate` | autogenerate | При разработке не было запущенного Postgres. Схема сверена через `alembic upgrade head --sql`; модели совпадают с миграцией (те же имена ограничений через `naming_convention`) |
